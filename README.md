# Week-04-React-PlanIt-NoteBloom
Week 04 React Minor Project featuring PlanIt, a task management app, and NoteBloom, a pastel aesthetic notes app built with React.js.
PlanIt & NoteBloom — Week 04 React Minor Project

A combined productivity website featuring PlanIt, a task management app, and NoteBloom, a pastel-themed notes app. Built using React.js as part of the Week 04 Web Development Minor Project.

 #Project Overview

This project combines two productivity tools in one website with a clean, aesthetic, and responsive interface.

#PlanIt — To-Do App

A task management application designed to help users organize their daily activities and stay productive.

#Features

- Add, edit, and delete tasks
- Mark tasks as completed or incomplete
- Set task priorities (Low, Medium, High)
- Add due dates
- Categorize tasks
- Search tasks
- Filter and sort tasks
- Track task completion progress
- Save tasks using Local Storage

#NoteBloom — Notes App

A soft, floral-inspired digital notes application for writing and organizing thoughts.

Features

- Create, edit, and delete notes
- Search notes
- Categorize notes
- Pin important notes
- Archive and restore notes
- Choose from pastel note colors
- Save notes using Local Storage

# Design

- PlanIt: Purple, lavender, white, and sky-blue color palette
- NoteBloom: Pastel colors with occasional brighter accents
- Soft floral decorations and aesthetic details
- Responsive design for desktop and mobile

# Tech Stack

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- Vite
- React Hooks ("useState", "useEffect", "useMemo")
- Local Storage

# Getting Started

1. Clone the repository

git clone https://github.com/YOUR-USERNAME/week04-react-planitnotebloom.git

2. Navigate to the project folder

cd week04-react-planitnotebloom

3. Install dependencies

npm install

4. Run the development server

npm run dev

Open the local URL displayed in the terminal to use the application.

# Build for Production

To create a production build:

npm run build

The production-ready files will be generated in the "dist" folder.

# Data Storage

The application uses browser Local Storage to save tasks and notes. Your data remains available after refreshing the page in the same browser, but it is not automatically synced between devices.
